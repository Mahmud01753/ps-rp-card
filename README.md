# Political Science Forum Editable Card

Design 2 is the fixed base artwork. `POLITICAL SCIENCE FORUM` remains fixed/non-editable.

Root files: index.html, style.css, script.js, logo-left.png, logo-right.png, portrait.png, README.md.

Photo is clipped to the existing photo area. Uploaded logos have edge background transparency applied. PNG export uses canvas.toBlob() and a temporary download link; editor controls are never exported.
