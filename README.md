# Political Science Forum — Editable Poster

## Files
- `index.html` — editable poster editor
- `logo-left.png` — Logo 1 (left)
- `logo-right.png` — Logo 2 (right)
- `portrait.png` — current portrait

## Editing
Open `index.html` in a browser.

You can:
- edit all poster text
- upload/replace portrait
- zoom portrait
- move portrait up/down/left/right
- change frame background color
- change frame color
- upload/replace either logo

### Replace files directly
To change a logo without editing HTML, replace:
- `logo-left.png` for the left logo
- `logo-right.png` for the right logo

To change the portrait directly, replace:
- `portrait.png`

Keep the same filenames.
